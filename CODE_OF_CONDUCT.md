# Code of Conduct

## Our standard

This project aims to be a welcoming place to collaborate. Be respectful, constructive, and considerate when opening issues, reviewing code, or participating in discussions.

Examples of positive behavior include:

- Giving clear, actionable feedback
- Respecting different levels of experience and points of view
- Focusing criticism on code and ideas rather than people
- Accepting reasonable maintainer decisions gracefully

Unacceptable behavior includes harassment, personal attacks, discriminatory language, threats, deliberate disruption, or publishing another person's private information without permission.

## Enforcement

Project maintainers may edit, remove, or reject comments, issues, pull requests, code, and other contributions that do not follow these standards. Repeated or serious violations may result in temporary or permanent exclusion from project spaces.

If you need to report conduct privately, contact the maintainer through their GitHub profile rather than opening a public issue containing sensitive information.
